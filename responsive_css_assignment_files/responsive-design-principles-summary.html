Responsive Design Principles

Fluid Layouts

Use percentages or flexible units instead of fixed pixel widths.

.container {"{ width: 90%; max-width: 1100px; }"}

Flexible Media

Images and videos should scale with their containers.

img {"{ max-width: 100%; height: auto; }"}

Breakpoints

Introduce media queries where the design naturally breaks.

@media (max-width: 600px) {"{ ... }"}
